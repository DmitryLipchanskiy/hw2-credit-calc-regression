## Жёсткие требования к коду

1. Все денежные величины — целые числа копеек. Number.isInteger должно быть true
   для каждого денежного поля результата.
2. Плавающая точка допустима ТОЛЬКО для месячной ставки i и аннуитетного коэффициента K
   (REQ-03). Результат умножения денег на i или K немедленно округляется half-up
   до целых копеек. Хранить деньги во float между операциями нельзя.
3. roundHalfUp НЕ реализуется через Math.round: Math.round(-1.5) === -1, а нам нужен
   half-up. Проверь своё решение на 1.5 → 2, 2.5 → 3, 1.4999 → 1.
4. Ветка нулевой ставки выбирается строго при annualRatePercent === 0 (REQ-13).
   Условия вида rate < 0.01, rate <= 0, !rate — ошибка.
5. calculateCredit не бросает исключений ни при каком входе. Невалидный вход —
   это { ok: false, errors: [...] }.
6. Без внешних зависимостей: только стандартная библиотека TypeScript/Node.
7. Комментарии в коде — на английском. В комментарии к каждой нетривиальной функции —
   ссылка на REQ-NN, который она реализует.
8. Код намеренно простой: без лишних слоёв абстракции и «расширяемости на будущее».
